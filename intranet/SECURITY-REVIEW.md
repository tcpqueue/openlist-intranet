# OpenList 内网版安全核查说明

版本：4.2.6+intranet3。核查日期：2026-09-09。

本次已修复确认可处理的安全问题，并完成离线运行及 ARM64 仿真回归。核查包含源码检查、依赖漏洞数据库扫描、接口负向测试、浏览器请求记录和安装脚本验证，不构成完整渗透测试或“零漏洞”承诺。

## 已处理的问题

| 项目 | 修复内容 |
| --- | --- |
| SSH 拒绝服务 | 将 golang.org/x/crypto 升级至 0.56.0，修复 GO-2026-6354、GO-2026-6355；同步升级 edwards25519 至 1.1.1。 |
| 前端依赖 | 更新 Svelte、DOMPurify、uuid，修复生产依赖扫描报告中的 14 条中低危告警。 |
| 旧 PPT 组件 | 替换 jQuery 1.11.3、JSZip 2.6.1，使用 jQuery 3.7.1、JSZip 3.10.1；新增 DOMPurify 清理和 ZIP 体积、条目数量限制。 |
| 空管理令牌 | 明确拒绝空字符串匹配管理令牌，避免配置被清空时将匿名请求识别为管理员。 |
| 上传鉴权 | 路径校验失败后立即中止 Gin 处理链，避免继续进入上传处理器。 |
| 登录限速 | 不信任客户端提供的转发 IP 头，防止伪造 X-Forwarded-For 绕过按 IP 限速。 |
| 本地文件边界 | 使用 os.Root 执行读取、创建、删除和重命名，阻止符号链接跳出存储根目录；禁用旧路径式缩略图解码、目录大小扫描和直接复制优化。 |
| SFTP 身份校验 | 必须填写并验证服务器 SHA256 主机密钥指纹，停止无条件信任服务器密钥。 |
| 浏览器及代理响应 | 固定同源资源策略，增加 nosniff、同源框架限制；过滤存储服务器返回的 Cookie 和安全策略覆盖头。 |
| 凭据输出 | 初次启动不再把初始密码打印到控制台或 systemd 日志。 |

## 外部资源限制

公共 Office、OCR、网盘驱动、第三方登录、Flash、EPUB、HTML 执行预览、URL 跳转预览、种子预览和离线下载工具已禁用或移除。PDF 字体、Office 预览库及界面资源随包提供。Markdown 外部图片与远程 README 不加载，自定义头尾和外部预览配置不可启用。

网络存储仅接受私有或回环 IP，不接受公网地址或域名；HTTP 代理关闭，重定向及 FTP 被动连接也检查目标地址。SFTP、SMB 的 localhost 转换为回环 IP。数据库仅使用本地 SQLite。以上限制针对本应用，不限制操作系统或其他程序的联网行为。

## 验证结果

- Go 漏洞扫描：0 个可调用的已知漏洞、0 个已导入包告警；依赖模块中仍列出 3 条未被本应用调用的告警，分别涉及旧 AWS S3 加密组件和已停止维护的 OpenPGP 包。未将它们表述为已经消除。
- 前端生产依赖扫描：0 条告警。单独分发的 PPT 旧依赖另行替换；扫描结果不覆盖所有手工分发资源的全部代码。
- Go 回归测试：本地文件边界、HTTP 地址与重定向策略、驱动和设置策略及相关现有测试通过。
- AMD64 与最终 deb 内的 ARM64 二进制：在无默认网络路由的独立命名空间运行，均通过 12 个页面的请求检查。PDF 中文、DOCX、XLSX、PPTX 预览和上传下载正常；已测试流程中未观察到外网请求、资源 HTTP 错误或页面未捕获异常。
- 负向接口测试：无效及空令牌、公开地址存储、符号链接越界读写、越界路径上传、未登录上传均被拒绝；伪造转发头仍触发登录限速。
- systemd：包内服务明确为 root/root；维护脚本通过 shell 语法检查及模拟命令测试，确认安装时 reload、enable、restart，卸载时 stop、disable。没有在麒麟实机执行安装。
- 二进制为静态 ARM64 ELF，无动态加载器；deb 使用 xz。无需 Go、Node.js、Python 或 glibc 动态运行库，安装服务仍依赖系统已有的 systemd。

页面内容安全策略会阻止 Vite 的 data URL 能力探测，浏览器随后使用随包提供的兼容脚本；测试中的此类控制台提示不涉及外网连接。

## 保留的运行风险和兼容性边界

按部署要求保留 root 运行和新装 admin/admin，已有密码不改。默认密码公开可猜；管理员可以添加本机目录，管理员凭据泄露可能危及主机文件。正式使用建议修改密码。HTTP 和普通 FTP 不加密传输；需要保密的网络应使用配置了证书的 HTTPS 和 SFTP。

文件边界不替代管理员权限管理，不隔离管理员明确配置的挂载点、硬链接或其他本机进程。回收站须放在对应存储根目录内。复杂业务文档、恶意压缩包资源耗尽以及并发压力场景仍需进一步验证。

目标为银河麒麟桌面 V10 ARM64、Linux 4.4。Go 公布的 Linux 最低内核要求涵盖 4.4，但本次 ARM64 验证使用 QEMU 用户态和 WSL 内核，不能证明麒麟 4.4 实机兼容性。最终部署需在目标机器验收启动、预览、文件访问和重启自启。
